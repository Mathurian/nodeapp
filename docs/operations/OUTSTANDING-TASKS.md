## Active / Pending Tasks

### 1. Contract Tests — JWT Global Mock Conflict

**Priority:** High
**Effort:** ~1–2 hours
**Background:** `tests/contracts/*.test.ts` return 401 because `jest.globalMocks.ts`
globally mocks `jsonwebtoken.verify` to return `{userId: 'mock-user-id', tenantId: 'mock-tenant-id'}`.
Real tokens generated by `generateTestToken()` can't be verified, so auth middleware rejects all requests.

**Fix:** Add `jest.unmock('jsonwebtoken')` (or `jest.resetModules()`) at the top of each
contract test file, before the other imports, so the real `jsonwebtoken` library is used.

**Files:**
- `tests/contracts/users.contract.test.ts`
- `tests/contracts/events.contract.test.ts`
- `tests/contracts/scoring.contract.test.ts`
- `tests/contracts/certifications.contract.test.ts`
- `tests/contracts/auth.contract.test.ts`
- `tests/jest.globalMocks.ts` (review whether JWT mock should be scoped more narrowly)

**Verification:** `npm run test:contracts` — all 35 tests should pass.
